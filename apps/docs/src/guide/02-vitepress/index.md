
# Vitepress Dökümantasyon

İlk projemiz dökümanlarımız için vitepress ile hazırlayacağımız statik bir site olacak.

Temel işlemleri tamamladığımızda sadece markdown dosyaları oluşturup-düzenleyerek dökümantasyonu güncel tutabileceğiz. 


Başlık (navigation bar) 
  - site ikonu
  - site adı
  
Başlıkta görünecek bağlantılar
  - Rehber -> Geliştirme adımlarımıza bu bağlantıdan ulaşacağız.
  - Sözlük -> Rehber kısmını sade ve küçük tutmak için kullandığımız araçlar ve terimlerin kısa açıklamaları
  - Plan   -> Yol haritamız

Giriş sayfası - Hero Page

Site içi arama (search)
